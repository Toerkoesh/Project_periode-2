Informatie

Hier kan je de informatie lezen van HTML CSS hoe het in elkaar zit.

HTML

HTML is de basis van een website. Het bepaalt de structuur en inhoud van een webpagina. Met HTML kun je bijvoorbeeld teksten, afbeeldingen, links, knoppen en formulieren toevoegen.

CSS

CSS zorgt ervoor dat een website er mooi en overzichtelijk uitziet. Je kunt hiermee bijvoorbeeld kleuren, lettertypes, afstanden en de indeling van een website aanpassen.
